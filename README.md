# TestTask_JuniorGameDesigner

O projekcie
Repozytorium zawiera rozwiązanie zadania rekrutacyjnego na stanowisko Junior Game Designer.

Część I - Responsywna strona internetowa
Strona internetowa wykonana przy użyciu HTML i CSS, bez plików graficznych ani frameworków.

Układ dynamicznie dostosowuje się do różnych szerokości ekranu.

Część II - Plan remontu pokoju
Plan remontu pokoju opisujący kolejne etapy prac w języku angielskim.

Struktura projektu:
index.html - struktura strony internetowej
style.css - style oraz układ kształtów
plan.txt - plan remontu pokoju
